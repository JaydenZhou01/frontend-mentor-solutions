### What I learned

This project helped me practice building a page from a visual design and separating the content structure from its presentation.

Some of the main things I practiced were:

- Using semantic elements such as `main`, `article`, `time`, and `figure`.
- Loading the local Figtree variable font with `@font-face`.
- Using `rem` units for scalable typography.
- Using `box-sizing: border-box` to keep padding and borders inside the card width.
- Creating a flexible card that fits smaller viewports with `width: 100%` and `max-width`.
- Using a media query to adjust typography for mobile screens.
- Adding a hover state to the article heading.

### AI collaboration

I used an AI assistant with the Copilot SDK in VS Code as a learning aid during this project. It helped me:

- Check and improve the semantic HTML structure.
- Troubleshoot the local font loading rule.
- Understand why the card width changed on mobile.
- Learn how `rem` units and media queries affect font sizes.
- Review CSS nesting and convert nested rules into standalone selectors.

The implementation and final styling decisions were tested and adjusted in the project while working through each issue.
